# Deep Learning Based Road Pothole Detection and Monitoring System

## Project Overview
This project focuses on detecting road potholes using deep learning and computer vision techniques.

## Technologies Used
- Python
- TensorFlow
- Keras
- YOLO
- OpenCV
- NumPy
- Matplotlib

## Key Features
- Detects potholes from road images.
- Identifies potholes using object detection.
- Displays bounding boxes around detected potholes.
- Supports road image and video analysis.
- Helps improve road monitoring and maintenance.
